대리콜 분석 단축어 - 빠른 설정 가이드

[단축어 앱]
1. + 새 단축어
2. 이름: 대리콜 분석
3. 세부사항에서 "공유 시트에서 보기" 켜기
4. 입력 유형: 이미지/사진
5. 동작 추가: "이미지에서 텍스트 추출"
6. 동작 추가: "URL"
   URL 형식:
   https://YOUR-GITHUB-ID.github.io/manager/?text=[텍스트]
7. 동작 추가: "URL 열기"

실제 사용:
카카오/T맵 → 스크린샷 → 사진 공유 → 대리콜 분석 → 결과 화면

중요:
- YOUR-GITHUB-ID.github.io/manager/ 부분은 실제 GitHub Pages 주소로 바꾸세요.
- [텍스트]는 URL 동작에서 "이미지에서 텍스트 추출"의 결과를 변수로 넣어야 합니다.
- 한글/특수문자는 URL 동작이 자동 인코딩하도록 변수로 넣으세요.
