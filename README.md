# 대리콜 매니저 FAST V2

목표: 카카오/T맵 대리 화면을 iPhone에서 캡처하고, iOS 단축어의 이미지 텍스트 인식으로 OCR한 뒤 이 PWA에 텍스트를 전달하여 즉시 점수를 계산합니다.

## 가장 빠른 사용법

1. 이 폴더를 GitHub Pages에 배포합니다.
2. iPhone Safari에서 사이트를 엽니다.
3. 홈 화면에 추가합니다.
4. 아래 "iOS 단축어 설정"을 한 번 만듭니다.
5. 카카오/T맵에서 스크린샷을 찍습니다.
6. 사진 공유 → "대리콜 분석" 단축어를 누릅니다.
7. 단축어가 이미지에서 텍스트를 추출하고 PWA를 `?text=` 주소로 열면 즉시 분석됩니다.

## iOS 단축어 설정

단축어 앱 → + → 이름을 "대리콜 분석"으로 설정.

동작:
1. "공유 시트에서 받기" 입력을 사진/이미지로 설정.
2. "이미지에서 텍스트 추출" 추가.
3. "텍스트"를 선택하여 추출 결과를 변수로 사용.
4. "URL" 동작 추가:
   https://YOUR-DOMAIN/manager/?text=[추출된 텍스트]
5. "URL 열기" 동작 추가.

공유 시트에서 이 단축어가 보이지 않으면 단축어 세부사항에서 "공유 시트에서 보기"를 켭니다.

주의: 이 버전은 OCR을 웹에서 하지 않고 iPhone 단축어가 먼저 수행합니다. 따라서 기존의 "사이트 열기 → 사진 선택 → 업로드" 단계를 줄일 수 있습니다.
