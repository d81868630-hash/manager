# 대리콜 매니저 PWA

아이폰 Safari에서 바로 실행하고 홈 화면에 추가할 수 있는 1차 PWA입니다.

## 포함 기능
- 카카오/T맵 대리 콜 스크린샷 선택
- 브라우저 OCR(Tesseract.js)로 한국어/영어 텍스트 추출
- 금액/출발/도착/거리/시간 추출
- 예상 시급 계산
- 0~100점 규칙 기반 추천
- 운행기록을 iPhone 로컬 저장소에 저장
- PWA manifest + Service Worker
- 샘플 콜 테스트

## 실행
PWA는 HTTPS 또는 localhost에서 서비스하는 것을 권장합니다.
정적 파일을 웹서버에 올린 후 iPhone Safari에서 주소를 열고:
공유 → 홈 화면에 추가 → 웹 앱으로 열기

## 중요
현재 OCR은 브라우저에서 동작하므로 첫 OCR 때 Tesseract.js 언어 데이터 로딩에 시간이 걸릴 수 있습니다.
또한 iPhone에서 캡처 이미지를 분석하는 방식이며 카카오/T맵 앱 내부를 직접 제어하거나 자동 수락하지 않습니다.
